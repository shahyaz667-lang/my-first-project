# Library Management System Using Data Structures

## Project Overview
This project is a simple Library Management System developed in C++.
It demonstrates the use of a **Singly Linked List** to store and manage book records.

## Data Structure Used
- Singly Linked List

## Main Features
1. Add a new book
2. Display all books
3. Search for a book by Book ID
4. Delete a book by Book ID
5. Exit the program

## Concepts Used
- Structures
- Classes and objects
- Pointers
- Dynamic memory allocation
- Singly linked list
- Traversal
- Searching
- Insertion
- Deletion
- Functions
- Conditional statements and loops

## How It Works
Each book is stored in a node of the linked list. Every node contains:
- Book ID
- Book title
- Author name
- Pointer to the next node

The program provides a menu through which the user can add, display, search, or delete books.
